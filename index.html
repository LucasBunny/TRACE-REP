Arquitetura do projeto

Stack & requisitos

Visão planejada das tecnologias que vão compor a versão completa do PI.

Planejamento técnico
⚛
React + JavaScript
Interface web · Planejado

Construção das páginas, formulários, gráficos, navegação e componentes acessíveis do sistema.

▦
Supabase + PostgreSQL
Banco de dados e serviços · Planejado

Armazenamento de equipamentos, medições, alertas, usuários e histórico de manutenções.

☁
Vercel + Supabase
Nuvem · Planejado

Hospedagem da interface e dos serviços de dados, com acesso remoto após configurar os ambientes.

⌘
API + MQTT
Integração de dados · Planejado

API para consultar e gerenciar registros do sistema; MQTT para telemetria enviada pelo ESP32.

⑂
Git + GitHub
Controle de versão · Planejado

Histórico de alterações, branches, revisão de código e trabalho colaborativo entre integrantes.

✓
Vitest + Testing Library + axe
Testes e acessibilidade · Planejado

Testes unitários e de componentes, verificação de fluxos essenciais e análise automatizada de acessibilidade.
